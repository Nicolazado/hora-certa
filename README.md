🕒 Hora Certa

O Hora Certa é uma plataforma desenvolvida para ajudar usuários a organizarem seus medicamentos de forma simples, prática e segura. O site permite cadastrar remédios, definir horários, receber lembretes automáticos e registrar as doses tomadas — garantindo mais controle e regularidade nos tratamentos diários.


---

🚀 Funcionalidades

📋 Cadastro de medicamentos
Adicione facilmente os remédios que utiliza no dia a dia.

⏰ Configuração de horários
Defina alertas personalizados para cada dose.

🔔 Lembretes automáticos
Receba notificações para não esquecer nenhum medicamento.

✔️ Registro de doses tomadas
Marque quando um medicamento foi ingerido, mantendo tudo organizado.

📊 Histórico detalhado
Acompanhe o uso de medicamentos e apresente o histórico em consultas médicas.



---

🎯 Público-Alvo

O sistema foi desenvolvido para atender diferentes perfis:

👵 Idosos

👨‍💼 Pessoas com rotina corrida

🧑‍⚕️ Cuidadores

📅 Usuários que precisam organizar tratamentos contínuos



---

💡 Objetivo

O Hora Certa busca oferecer uma forma acessível e confiável de acompanhar tratamentos, contribuindo para uma maior segurança e eficiência no uso de medicamentos.
